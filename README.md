# Student Performance Prediction using Machine Learning

## Project Overview

Student Performance Prediction is a Machine Learning project that predicts a student's final score based on academic factors such as study hours, attendance, previous score, and assignment completion.

The project uses Linear Regression to learn patterns from student performance data and predict the expected final score for a new student.

## Features

- Load student performance data from a CSV file
- Train a Machine Learning model
- Predict final student scores
- Evaluate model performance
- Display Actual vs Predicted scores using a graph
- Provide a simple performance classification

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Machine Learning
- Git & GitHub

## Machine Learning Algorithm

Linear Regression

### Input Features

- Study Hours
- Attendance
- Previous Score
- Assignment Completion

### Target

- Final Score

## Machine Learning Process

1. Load the dataset
2. Separate input features and target
3. Split data into training and testing sets
4. Train the Linear Regression model
5. Make predictions
6. Evaluate the model using MAE and R² Score
7. Predict the performance of a new student
